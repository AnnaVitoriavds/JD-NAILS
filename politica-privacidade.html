Política de Privacidade

Esta página apresenta um modelo simples para o Studio JD. Antes da publicação definitiva, ajuste os dados conforme a forma real de atendimento e tratamento de informações.

Dados enviados

Ao usar o formulário de agendamento, você pode informar nome, telefone, serviço de interesse, data preferida e observações.

Finalidade

Os dados são utilizados exclusivamente para iniciar o atendimento, verificar disponibilidade, organizar o agendamento e responder dúvidas relacionadas ao serviço.

WhatsApp

O formulário deste site gera uma mensagem e abre o WhatsApp. O envio somente acontece quando a própria pessoa confirma a mensagem no aplicativo.
